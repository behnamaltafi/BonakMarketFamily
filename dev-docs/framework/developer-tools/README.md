# Developer Tools

BonakMarket includes small utilities for maintaining assets, packaging extensions, and testing the Web API. They are located in the repository's `tools` directory and are intended for development and release workflows.

| Tool                                             | Purpose                                                                                                                     | Source code                                                                                                        |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| [BonakMarket Packager](packager.md)               | Creates installable ZIP packages for compiled BonakMarket modules and themes, either interactively or from the command line. | [Desktop](../../../tools/BonakMarket.Packager) · [CLI](../../../tools/BonakMarket.Packager.Cli)                      |
| [BonakMarket Web API Clients](web-api-clients.md) | Provides Windows and JavaScript reference clients for composing, sending, and inspecting BonakMarket Web API requests.       | [.NET](../../../tools/BonakMarket.WebApi.Client) · [JavaScript](../../../tools/BonakMarket.WebApi.Client.JavaScript) |
